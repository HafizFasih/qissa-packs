How to install

1 In Qissa Studio (easiest)

Open Qissa Studio → Marketplace on Home → pick a pack → Install. Its items appear in the editor at once.

2 From this site

Open in app on a pack opens the app on that pack. Or Download the zip, then in the editor: Reel settings → Packs → Install pack (.zip).

3 Use it

Items are named pack-id/item, for example ramadan-essentials/lantern. AI assistants connected to Qissa Studio see them too.

Every pack is CC0 or MIT style: free for any use. Licences are inside each zip.
